# AGENTS.md

RouterWatch — TUI-монитор сетевого трафика с привязкой запросов к устройствам
локальной сети. Python + Textual, без внешних зависимостей кроме Textual.

## Возможности
- Первый запуск: выбор языка RU/EN (сохраняется).
- Настройки: IP роутера, логин, пароль, интерфейс, режим захвата.
- Дашборд: время, устройство, тип (DNS/HTTPS/HTTP), читаемый URL, размер.
- Имена устройств: DHCP-таблица роутера + DHCP/mDNS/ARP.
- Понятные названия (`iPhone 15 Pro`, `Pixel 10a`, `Galaxy S23`); без имени —
  бренд по MAC (OUI из `/usr/share/hwdata/oui.txt`, есть запасной список).
- Опциональный MITM для трафика других устройств.

## Структура
- `app.py` — Textual: LanguageScreen, SetupScreen, DashboardScreen, DevicesScreen.
- `sniffer.py` — пассивный AF_PACKET: DNS(53), TLS SNI(443/…), HTTP Host(80/…),
  DHCP(67/68), mDNS(5353), ARP. Дедуп 1.5 с, лимит строк 2000.
- `router_client.py` — вход в админку Realtek Boa, парсинг DHCP-клиентов.
- `config.py` — конфиг, автоопределение шлюза/интерфейса/сети/MAC.
- `device_names.py` — нормализация hostname и бренд по MAC (OUI).
- `i18n.py` — строки RU/EN.
- `tests/` — unittest: парсинг пакетов, md5-crypt, UI через Textual pilot.

## Запуск
```bash
sudo ./routerwatch
```
Root нужен для AF_PACKET. Если запустить без sudo, лаунчер сам вызовет `sudo -E`.
Конфиг: `~/.config/routerwatch/config.json` (права 0600).

## Тесты
```bash
python3 -m unittest discover -s tests -v
```

## Режимы захвата
- По умолчанию — только трафик этого компьютера (безопасно).
- `capture_all` (MITM) — ARP-спуфинг, `ip_forward=1`; при остановке ARP и
  `ip_forward` восстанавливаются. На Wi-Fi точка доступа может блокировать
  пересылку client→client, лучше Ethernet. По умолчанию выключено.

## Ограничения
- Бытовые роутеры не отдают лог каждого запроса; используется пассивный сниффер.
- HTTPS: виден домен (SNI), но не путь и не содержимое.
- Чтение DHCP-таблицы (`/dhcptbl.asp`) выключено по умолчанию: на некоторых
  прошивках Realtek эта страница подвешивает веб-сервер роутера. Включается
  в настройках (`router_dhcp_table`).
- Запускать только в своей сети и только с согласия владельца.

## Соглашения
